# Портфолио разработчика

Разрабатываю прикладные веб-сервисы и desktop-приложения: автоматизирую рабочие процессы, интегрирую внешние API и превращаю разрозненные данные в понятные инструменты для пользователей.

Здесь собраны демонстрационные версии проектов и технические описания. Для каждого решения указаны задача, ключевые функции и технологии. Данные обезличены; примеры с ценами и объектами вымышлены.

## Проекты

| Проект | Что решает и что реализовано | Технологии |
|---|---|---|
| [ИИ-ассистент с базой знаний](projects/knowledge-assistant-demo/) | Встраиваемый чат с RAG-поиском по справочным материалам, индексом SQLite, источниками ответа, ограничением запросов и API для виджета. | Python, SQLite, OpenAI API, HTML/CSS/JS, Docker |
| [Dental CAD Library Updater](projects/library-updater-demo/) | Desktop-приложение для инвентаризации версий библиотек, поиска обновлений, загрузки и установки пакетов с резервным копированием. Дополнено сканером архивов и примером аналитического API. | C#, .NET 8, WPF, MVVM, Python, PHP, MySQL |
| [Система назначения и учета процедур](projects/procedure-management/) | Учет клиентов и истории посещений, каталог услуг, расписание с проверкой пересечений, роли сотрудников и журнал действий. | PHP, SQLite, Bootstrap |
| [Аналитика анкет](projects/survey-analytics/) | Импорт ответов из форм и почты, управление вопросами, дашборд оценок, динамика удовлетворенности, NPS и комментарии. | PHP, MySQL, IMAP |
| [Оплата электронными сертификатами](projects/certificate-checkout/) | Оформление заказа с оплатой сертификатом, банковской картой или комбинированным способом; интеграция с платежным API и обработка webhook. | PHP, MySQL, YooKassa API |
| [Telegram Order Bot](projects/telegram-order-bot/) | Диалоговый прием заказов, проверка позиций каталога, расчет скидок и уведомления. | Python, aiogram, MySQL |
| [Download Analytics](projects/download-analytics/) | API и панель для сбора и просмотра агрегированных событий desktop-приложения. | PHP, MySQL |
| [Archive Metadata Scanner](projects/library-scanner/) | Поиск XML-метаданных в ZIP-архивах и подготовка структурированного CSV-отчета. | Python |
| [Blender Batch Rendering](projects/blender-batch-rendering/) | Скрипты для пакетной подготовки STL-моделей и сцен рендеринга. | Python, Blender |

## Технологии и задачи

**Языки и платформы:** C#, .NET, WPF, PHP, Python, SQL, HTML/CSS/JavaScript.  
**Интеграции и инфраструктура:** REST API, webhook, IMAP, Telegram, платежные API, SQLite, MySQL, Docker.  
**Типы решений:** веб-сервисы, desktop-приложения, автоматизация, обработка архивов, аналитика и инструменты для внутренних процессов.
