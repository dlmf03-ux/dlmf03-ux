# Procedure Management Demo

Обезличенная PHP/SQLite веб-система для планирования назначений и учета сеансов услуг. Демонстрационный кейс показывает полный рабочий процесс: от карточки клиента и назначения до расписания, оплаты, печатной формы и аудита.

## Возможности

- Карточки клиентов и история назначений.
- Каталог услуг и расписание отдельных сеансов с проверкой пересечений.
- Учет оплат и статусов выполнения.
- Роли администратора и менеджера, CSRF-защита, журнал действий.
- Архивация и восстановление записей, печатная форма A4.

## Устройство и стек

Приложение написано на PHP 8.1+ с SQLite через PDO, Bootstrap и локальными CSS/JS-ресурсами. База создается при первом запуске; каталог `storage/` должен быть доступен PHP для записи. Структура приложения разделяет маршрутизацию, бизнес-логику и представления.

## Локальный запуск

Требуются PHP 8.1+, расширения PDO SQLite и mbstring.

1. Склонируйте репозиторий и убедитесь, что `storage/` доступен для записи.
2. Запустите локальный сервер из каталога проекта: `php -S 127.0.0.1:8080 router.php`.
3. Откройте `http://127.0.0.1:8080` и завершите локальный сценарий первоначальной настройки.
4. Для демонстрации используйте только вымышленные записи.

Не выставляйте демонстрационный сервер в интернет и не вводите реальные медицинские или персональные данные.

## Обезличивание и ограничения

Производственная база, токены установки, брендовые материалы, прайс-листы, готовые выгрузки и временные файлы исключены. Названия и суммы демонстрационные. Перед реальным внедрением потребуются проверка требований к защите данных, резервное копирование, контроль доступа и отдельный аудит безопасности.
