# Blender Batch Rendering Demo

Набор Blender Python-скриптов для автоматизации подготовки 3D-моделей STL к визуализации. Примеры охватывают импорт и первичную проверку сетки, ориентацию объекта, материалы, освещение, ракурсы и разделение материала по плоскости.

## Что входит

- Скрипт подготовки STL-сетки и демонстрационной обработки.
- Скрипт настройки материалов, камеры и рендер-сцены.
- PowerShell-заготовка командного запуска `run_mvp.ps1`.

## Требования и запуск

Нужен установленный Blender 4.x с Python API и импортом STL. В репозитории нет коммерческих моделей, подготовленной рабочей сцены или готовых ресурсов для рендера; перед запуском укажите локальный Blender и собственную сцену/модель, на которые у вас есть права. `run_mvp.ps1` — пример для адаптации под локальные пути, он требует настройки.

## Ограничения и обезличивание

В демонстрационной копии отсутствуют исходные производственные модели и сцены. Некоторые шаги рендеринга являются шаблонами, а не универсальным конвейером: проверьте настройки на тестовой геометрии и Blender вашей версии. Добавляйте в публичный репозиторий только модели, материалы и текстуры, права на которые у вас есть.

**Лицензия:** пока не выбрана. Публичность репозитория не означает разрешение на повторное использование кода.
