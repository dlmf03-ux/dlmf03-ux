# Survey Analytics Demo

PHP/MySQL-приложение для импорта ответов на веб-анкеты из уведомлений по электронной почте и анализа обратной связи. Сервис помогает собрать ответы в одном месте и следить за оценками и NPS.

## Возможности

- Ручной импорт и импорт писем по IMAP.
- Управление формами и вопросами.
- Дашборд удовлетворенности, динамика оценок и расчет NPS.
- Просмотр импортированных комментариев и периодический запуск импорта через cron.

## Структура и стек

- `public/` — страницы входа, анкет, ответов, импорта и панели.
- `app/` — конфигурация, авторизация, разбор писем, импорт и метрики.
- `database/` — схема и миграции.
- `cron/import_mail.php` — плановый импорт по IMAP.

Требуются PHP 7.4+, PDO MySQL, MySQL/MariaDB; для автоматического импорта — расширение PHP IMAP.

## Локальный запуск

1. Создайте отдельную пустую тестовую базу и импортируйте `database/schema.sql`.
2. Скопируйте `.env.example` в `.env` и заполните параметры локальной БД.
3. Настройте локальный веб-сервер с корнем в `public/`, либо выполните из каталога проекта:

   ```bash
   php -S 127.0.0.1:8080 -t public
   ```

4. Используйте синтетические ответы. Не подключайте production-почту или реальные анкеты.

Для обзора парсера есть `tools/check_eml_parser.php`; запускайте его только на синтетических письмах.

## Данные и ограничения демо

В копии нет настоящих `.env`, писем, ответов респондентов, логотипов и параметров подключения. Демонстрационные вопросы обобщены. Интеграция с почтой требует отдельной тестовой почтовой учетной записи. Перед реальным использованием определите политику хранения данных, доступ к почте, удаление персональных данных и защиту веб-приложения.
