# Certificate Checkout Demo

Демонстрационный checkout для оформления услуги с оплатой электронным сертификатом, банковской картой или смешанным способом. Проект показывает интеграционный поток оплаты: формирование заказа, создание платежа у провайдера, сохранение статуса и обработку webhook.

## Возможности и поток

- Проверка полей формы, выбранной суммы и способа оплаты.
- Создание демонстрационной брони и записи платежа в MySQL.
- Идемпотентный запрос к платежному API с данными позиции и чека.
- Обработка уведомлений провайдера и отображение успешного/отмененного результата.
- Отправка статусного письма через настроенный SMTP.
- Сценарии использования сертификата, карты и комбинированной оплаты.

## Стек

PHP 8+, PDO MySQL, cURL, MySQL-совместимая БД; внешний платежный API и SMTP подключаются настройками. `config.php` — безопасный загрузчик `config.sample.php`; секреты в репозитории отсутствуют.

## Локальный запуск

1. Установите PHP 8+ с PDO MySQL и cURL и подготовьте отдельную тестовую БД.
2. Импортируйте `install.sql`.
3. Скопируйте `.env.example` в локальный `.env` и задайте только тестовые параметры. Не добавляйте `.env` в Git.
4. Запустите из каталога проекта: `php -S 127.0.0.1:8080`.
5. Для внешнего webhook потребуется доступный тестовый endpoint; используйте туннель только с sandbox-учетной записью.

Используйте вымышленные имена и адреса на `example.com`. Не указывайте реальные номера сертификатов, персональные данные или production credentials. Не подключайте проект к реальному магазину.

## Обезличивание и ограничения

В публичной копии нет реальных сертификатов, записей клиентов, договоров, согласий, логотипов, production URL или учетных данных. Коды услуг и сертификатов — placeholders. Возможности сертификатной оплаты и требования к чекам зависят от провайдера и учетной записи; перед любым реальным внедрением необходима отдельная проверка API, юридических требований и безопасности.
