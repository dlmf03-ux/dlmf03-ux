# Download Analytics API Demo

Демонстрационный PHP API и панель аналитики для событий жизненного цикла desktop-приложения. Клиент может отправить установку, запуск, проверку обновлений, скачивание файла или результат операции; панель показывает сводные метрики.

## Как работает

1. Клиент отправляет событие в `api/events.php`.
2. API проверяет тип события и ограничивает длину полей.
3. Событие сохраняется в MySQL через `lib/db.php`.
4. `index.php` показывает сводку, популярные загрузки и результаты операций.

Поддерживаются `app_install`, `app_start`, `check_updates`, `library_download`, `library_operation`.

## Стек и запуск

PHP 8+, PDO MySQL, MySQL, HTML/CSS.

1. Создайте отдельную тестовую БД и импортируйте `schema.sql`.
2. Скопируйте `config.sample.php` в локальный `config.php` и задайте тестовые параметры БД и администратора через переменные окружения.
3. Запустите локальный сервер из каталога проекта:

   ```bash
   php -S 127.0.0.1:8080 -t .
   ```

Отправляйте только синтетические тестовые события.

## Безопасность и приватность

В публичной копии нет production URL, учетных данных или дампов. Схема содержит поля сетевых метаданных; для реальной системы нужно минимизировать сбор данных, определить срок хранения и ограничить доступ к API и панели. Демо не предназначено принимать production-трафик без дополнительной защиты, контроля доступа и политики хранения.

**Лицензия:** пока не выбрана. Публичность репозитория не означает разрешение на повторное использование кода.
