# Telegram Order Bot Demo

Обезличенный асинхронный Telegram-бот для пошагового оформления заказа. Бот собирает контактные данные и адрес доставки, принимает список товаров, сверяет позиции и количества с каталогом, рассчитывает скидку и уведомляет администратора.

## Компоненты

- `app/bot_logic.py` — состояния диалога и действия пользователя.
- `app/handlers.py` — обработчики сообщений и callback-запросов.
- `app/keyboards.py` — inline-клавиатуры.
- `app/services/order_service.py` — разбор заказа, проверка количества и расчет.
- `app/repositories/` — работа с пользователями, заказами, каталогом и промокодами.
- `app/config.py` — параметры из переменных окружения.

## Стек и зависимости

Python 3.10+, aiogram 3, aiomysql, MySQL, aiosmtplib. Запуску нужны токен отдельного тестового Telegram-бота и MySQL-схема с таблицами пользователей, заказов, товаров и промокодов. Эта обезличенная папка не содержит производственную схему или данные; структура БД зависит от вашего локального окружения и ее потребуется подготовить отдельно.

## Локальная настройка

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env`, укажите тестовый токен, локальные параметры тестовой БД и запустите:

```bash
python -m app.main
```

Не используйте production-бота, реальные адреса и телефоны, действующие учетные записи или рабочую БД. `.env` не должен попадать в Git.

## Обезличивание и границы примера

В демо заменены брендовые тексты, контакты, адреса, email, артикулы и параметры подключения. Перед публикацией проверьте права на исходную бизнес-логику. Для публичного воспроизводимого стенда потребуется добавить отдельную синтетическую схему и фиктивный каталог.
