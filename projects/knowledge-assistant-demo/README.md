# Демонстрационный ИИ-ассистент с базой знаний

Встраиваемый чат-виджет отвечает на вопросы по локальной базе знаний. Для поиска используются лексическое ранжирование и, при настройке API-ключа, семантические эмбеддинги; генерация ответа получает найденные фрагменты как контекст. Если подходящей информации нет, ассистент сообщает об этом.

## Возможности

- RAG-поиск по локальной базе JSON с хранением индекса и кэша в SQLite.
- Опциональная генерация ответов и embeddings через OpenAI API.
- Виджет для встраивания на страницу и самостоятельная демо-страница.
- Ограничение частоты запросов, проверка Origin, ограничение размера запроса и health endpoint.
- Источники найденных фрагментов возвращаются клиенту; тексты вопросов намеренно не записываются в журнал сервера.

## Стек и структура

- Python 3.12, стандартный `http.server`, SQLite.
- HTML, CSS и JavaScript для чата.
- Docker и Docker Compose для локального запуска.
- `app/rag.py` — подготовка, индексация и поиск по фрагментам.
- `app/openai_client.py` — клиент генерации и embeddings.
- `app/server.py` — HTTP API, виджет, кэш и базовые ограничения запросов.
- `data/knowledge.json` — полностью синтетический набор примеров.

## Запуск

Скопируйте `.env.example` в `.env`, при необходимости добавьте собственный API-ключ в локальный файл, затем запустите:

```powershell
Copy-Item .env.example .env
docker compose up --build
```

Откройте `http://localhost:8080/demo`. Без API-ключа поиск по локальной базе продолжает работать, но генеративные ответы и embeddings отключены. Не добавляйте секреты в Git.

Внешний веб-поиск в этой демонстрации отключен. Чтобы встроить виджет на собственный сайт, задайте `ALLOWED_ORIGINS` и URL API на своей инфраструктуре.
