# Dental CAD Library Updater Demo

Обезличенный демонстрационный проект Windows-приложения для инвентаризации, установки и обновления библиотек, совместимых с dental CAD-средой exocad. Это расширенная версия идеи сканера архивов: приложение сопоставляет каталог доступных пакетов с локально установленными версиями и проводит пользователя через обновление.

## Что делает

- Загружает CSV-каталог библиотек и разделяет записи по категориям.
- Сканирует выбранные локальные папки и читает версию/поставщика из `config.xml`.
- Показывает отсутствующие и устаревшие библиотеки, поддерживает фильтры.
- Загружает архивы с повторными попытками, распаковывает их и устанавливает.
- При обновлении сохраняет резервную копию и предусматривает восстановление при ошибке.
- Поддерживает автоматические проверки, системный трей, журнал событий и настройки пользователя.
- Включает отдельный Python-сканер архивов для извлечения метаданных в CSV и пример PHP/MySQL API с панелью агрегированной телеметрии.

## Архитектура и технологии

- `src/LibraryUpdaterDemo/` — клиент WPF на C#/.NET 8 с MVVM.
- `Services/` — загрузка CSV, сканирование локальных папок, скачивание/распаковка и установка.
- `ViewModels/`, `Views/`, `Models/` — состояние интерфейса, XAML-экраны и модели.
- `Server/scan_library.py` — извлечение метаданных архивов в CSV.
- `Server/analytics/` — демонстрационный PHP/MySQL endpoint и страница статистики.
- Основные библиотеки: CommunityToolkit.Mvvm, H.NotifyIcon.Wpf, SharpCompress и SharpVectors.Wpf.

## Сборка клиента

Требуется Windows и .NET 8 SDK с поддержкой WPF. Откройте PowerShell в корне репозитория и выполните:

```powershell
dotnet restore .\LibraryUpdaterDemo.sln
dotnet run --project .\src\LibraryUpdaterDemo\LibraryUpdaterDemo.csproj
```

В обезличенной копии URL CSV-каталога и телеметрии по умолчанию пустые, а скачивание направлено на зарезервированный домен `example.invalid`. Приложение не подключено к рабочему источнику и не предназначено для установки реальных пакетов без настройки собственного тестового каталога и безопасного хранилища синтетических архивов. Локальные пути библиотеки задаются пользователем в интерфейсе.

## Сканер и серверная часть

Python-сканер использует `config.xml` внутри ZIP; для RAR нужен отдельно установленный Python-пакет `rarfile` и системная утилита `unrar`. Скрипт не устанавливает системные пакеты самостоятельно. Каталог входных файлов и путь результата можно задать переменными `LIBRARY_SCAN_DIR` и `LIBRARY_SCAN_OUTPUT`. Используйте только фиктивные архивы.

PHP endpoint требует PHP с PDO MySQL, отдельную тестовую базу и собственный файл `config.php`, создаваемый локально на основе `Server/analytics/config.sample.php`. Реальные настройки исключены. Полная производственная схема и данные в портфолио не входят; перед запуском серверной части потребуется подготовить тестовую схему. Админ-панель собирает агрегированную аналитику и может сохранять IP/сетевые метаданные, поэтому оставлена как пример и не должна публиковаться в рабочем окружении без отдельного решения по приватности и безопасности.

## Обезличивание и ограничения

Исключены оригинальный бренд, логотипы, установщики, собранные бинарные файлы, production URL, рабочая конфигурация и учетные данные. Каталоги, поставщики, CSV URL и аналитический endpoint заменены нейтральными примерами. Телеметрия отключена пустым URL по умолчанию. Название exocad используется только для описания совместимости; проект не аффилирован с правообладателем этой торговой марки.

В репозитории приведен исходный код демонстрационной версии, а не готовый публичный сервис обновлений. Перед использованием в реальной среде необходимы тестирование безопасного формата каталогов, проверка архивов, контроль целостности пакетов, защита API и резервное копирование.

**Лицензия:** пока не выбрана. Публичность репозитория не означает разрешение на повторное использование кода.
