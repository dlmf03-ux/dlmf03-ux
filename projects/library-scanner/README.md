# Archive Metadata Scanner

Python CLI для инвентаризации ZIP-архивов: ищет внутри `config.xml`, извлекает версию и поставщика и формирует CSV-отчет. Подходит как пример автоматизации обработки локального набора архивов.

## Использование

```bash
python scan_archives.py ./sample-archives ./output/inventory.csv
```

В отчете указываются относительный каталог, имя архива, версия и поставщик. Отсутствующий или нечитаемый XML отражается в строке результата. Скрипт не обращается к серверу и не включает исходные архивы.

## Технологии и границы

Python 3.10+ и стандартная библиотека: `zipfile`, `csv`, `argparse`, `xml.etree`. Текущий пример поддерживает только ZIP; форматы 7z/RAR не входят в эту версию.
